# SalCAPA v2.0 — platform foundation

- Repositions the validated Salus THIRA Command foundation as the SalTHIRA component of SalCAPA.
- Adds a server-controlled Protected Member and Salus personnel workspace contract.
- Adds a shared SalCAPA Common Operating Picture.
- Adds SalINTEL collection and controlled qualification records.
- Adds governed SalINTEL-to-SalTHIRA reassessment handoff without duplicate triggers.
- Adds SalOPS requests, authorization, assignment, completion, and operational-result feedback.
- Adds governed SalTHIRA-to-SalOPS handoff requiring an approving executive decision.
- Prevents client payloads from forging component lifecycle, provenance, authority, audit, or handoff state.
- Preserves tenant isolation, audit history, deterministic reconstruction, and SQLite/PostgreSQL parity.
