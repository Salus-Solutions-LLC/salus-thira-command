# SalCAPA v3.137

## Governed Microsoft 365 document ingestion

- Captures approved files only from the configured exact OneDrive/SharePoint intake folder as immutable, tenant-scoped material records.
- Preserves source identity and version, timestamps, owner/modifier, trusted source URL, SHA-256 integrity, sensitivity, purpose, and authority basis.
- Connects governed sources to bounded text, Word, Excel, PowerPoint, PDF, and image extraction while preserving derivative lineage.
- Requires independent human review before a derivative can enter the tenant- and clearance-scoped SalINTEL research index.
- Routes indexed source aids into SalTHIRA evidence only through a separate authorized human action; evidence remains pending verification and creates no automatic finding, decision, priority, recommendation, or disclosure authority.
- Detects changed and missing Microsoft 365 source versions and requires a single-use System Administrator authorization before immutable reprocessing.
- Adds representative end-to-end multi-format acceptance inside the production container, including access-boundary, attribution, review, indexing, routing, and reprocessing controls.
