# SalCAPA v3.131

## Scrollable workspace navigation

- Gives the fixed left navigation its own vertical scroll area.
- Makes lower SalINTEL, SalTHIRA, SalOPS, and supporting links reachable on shorter displays.
- Supports mouse wheel, touchpad, keyboard, and touch scrolling.
- Contains sidebar overscroll so the main workspace does not move unexpectedly.
- Preserves the responsive mobile layout and existing authorization boundaries.
- Restyles the session action as the Salus-orange `< Sign Out` control for consistent action hierarchy.
