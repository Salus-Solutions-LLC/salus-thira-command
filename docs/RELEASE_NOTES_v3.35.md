# SalCAPA v3.35 release notes

## Salus visual system and in-product guidance

SalCAPA v3.35 aligns the shared application interface with the approved Salus
visual language while preserving the information density and authority controls
required for protective operations. The application uses a light, restrained
canvas, deep-navy structural navigation, restrained teal interaction accents,
and a system-font Avenir/Helvetica-style stack. SalINTEL remains blue/cyan,
SalTHIRA remains amber/gold, SalOPS remains green/teal, and red remains reserved
for urgent or error conditions.

The official supplied Salus Solutions horizontal logo replaces the temporary
navigation mark. The supplied stacked logo is retained as a governed application
asset for spacious authentication, reporting, and presentation contexts. The
artwork is not recolored, approximated, or replaced.

A persistent Help / How SalCAPA Works control, role-aware breadcrumbs, and the
See → Decide → Coordinate → Act → Prove orientation strip now accompany every
major workspace. Contextual field help explains unfamiliar concepts through
hover, keyboard focus, and click/tap paths. Empty states explain what belongs in
a workspace and the governed next action. A responsive Salus workflow graphic
keeps Protected Members central while explaining how SalINTEL, SalTHIRA, and
SalOPS support the integrated operating environment.

The guidance layer is presentation-only. It cannot call application APIs,
submit forms, change records, or bypass role, tenant, lifecycle, provenance,
evidence, approval, or audit controls. Keyboard focus, Escape-to-close,
focus restoration, responsive behavior, print suppression, and accessible SVG
descriptions are enforced by deterministic acceptance checks.

All product, database, container, dependency, security, repository, Azure-policy,
deterministic-reconstruction, and CodeQL gates remain required before release
freeze. No Azure resource, credential, DNS record, or production environment is
changed by this release.
